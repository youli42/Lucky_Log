## 视图

### 总览大屏（Overview）
- KPI 卡片：日志总量 / Web 访问 / 活跃服务 / 采集状态（最近采集时间、错误）。
- 图表：模块分布（环形）、日志趋势（折线）、Web 访问趋势（折线）、服务分布（条形）。
- 最近日志实时流：实时模式开启时新日志插入表格顶部。

### Web 访问分析（Access，`/access`）
- **访问分析 Tab**：KPI（总访问/独立 IP/独立路径/域名/**总流量/连接总数**）+ 访问趋势 + 访问 IP 排行 + **IP 排行明细表**（IP/归属地/请求数/连接/流量入出/最后访问）+ 地区分布 + 浏览器分布 + 操作系统统计 + 来源类型（设备类型环形 + Host 域名分布）+ 设备型号 + 访问路径 Top + 请求方法。
- **访问明细 Tab**：按 IP / 路径 / UA 关键词筛选，分页表格，导出 CSV。
- **运行日志 Tab**：规则层 httpserver 日志（如 TLS 握手错误），`level=rule` 过滤。
- 筛选：规则 / 子代理 / 域名 / 关键词。

## 完整信息展示（明细表格，不臃肿）

三级渐进：**表格精简 → 悬停 Tooltip → 行点击详情抽屉**。

- **默认列**：时间 | 归属地(省·市) | IP | 方法 | 路径 | 客户端(浏览器·OS)；长字段省略号 + hover 完整 title。
- **IP 悬停 Tooltip**：浮层显示完整归属地（国家/省份/城市/ISP）+ 连接数/流量入出/最后访问。
- **行点击 → 右侧详情抽屉**（滑出 + 遮罩 + Esc，可滚动）：
  - 请求：时间、方法、路径、Host、规则/子代理、设备类型
  - 访问者：IP、国家、省份、城市、ISP、连接数(快照)、流量入/出、最后访问
  - 客户端：浏览器(+版本)、操作系统(+版本)、设备品牌/型号、原始 UA（一键复制）
- **⚙ 列显隐配置**：可开关 时间/IP/归属地/国家/省/市/ISP/方法/路径/域名/浏览器/浏览器版本/OS/OS版本/设备/设备型号/UA/流量 等 22 列，选择存 localStorage。
- **全部历史 IP 列表**：访问分析页下方按 IP 去重的全量分页列表（Top15 图表仅用于可视化，列表完整），支持按 IP 关键词筛选，点击行跳转该 IP 的访问明细。
- 后端富化（查询时，不改表）：`/api/access/logs` 每行附 `geo{country,province,city,isp}`、`browser_version/os_version/device_brand/device_model`、`geo_short`（省·市）、`connections/traffic_in/traffic_out/last_access`；导出同全字段。
- 快照数据（连接/流量）在访问分析页每 30s 自动刷新，筛选区标注「更新于 HH:mm:ss」。

### 模块通用日志视图（ModuleLogs，`/module/:module`）
- 筛选：服务（webservice 时联动，规则 + 子代理，含条数）、去重、关键词。
- 趋势图 + 日志表格 + 分页 + CSV/JSON 导出。

## 模式

### 实时模式
- 前端订阅 `WS /ws/stream`（单连接，事件广播给各视图）。
- 新日志实时插入表格顶部 + 图表增量刷新；断线自动重连。
- 仍保留「手动刷新」按钮。

### 手动模式
- 不订阅 WS；点击「手动刷新」才请求最新数据。
- 后端始终持续采集入库，手动刷新即查询最新。

## 后端 API

| 接口 | 说明 |
|---|---|
| `GET /api/instances` | 实例列表 + 状态 + 已配置模块 |
| `GET /api/services?instance=` | 服务树 + 规则/子代理日志条数 |
| `GET /api/modules?instance=` | 模块列表 + 条数 |
| `GET /api/overview?instance=&from=&to=` | 总览 KPI + 模块分布 + 趋势 |
| `GET /api/logs?instance=&module=&service=&level=&from=&to=&search=&dedup=&page=&pageSize=` | 日志分页（service 匹配规则或子代理；level=rule/sub） |
| `GET /api/stats?...` | 图表统计 |
| `GET /api/access/stats?instance=&rule=&sub=&host=&from=&to=&granularity=` | Web 访问统计（IP/路径/浏览器/OS/设备/域名/地区 + 流量快照） |
| `GET /api/access/logs?instance=&rule=&sub=&host=&ip=&path=&search=&page=&pageSize=` | 访问明细分页（每行附完整归属地 + UA 版本 + 流量） |
| `GET /api/access/ips?instance=&rule=&sub=&host=&search=&page=&pageSize=` | **全部历史 IP 分页**（次数/归属地/流量，不再限于 Top15） |
| `GET /api/access/export?format=csv|json` | 访问日志全字段导出 |
| `GET /api/export?format=csv|json` | 通用日志导出 |
| `WS /ws/stream` | 实时增量推送 |
| `GET /api/config` | 读取当前配置（含 token 与模块清单） |
| `POST /api/config/test` | 用表单值测试连接（`/api/status`，不保存） |
| `PUT /api/config` | 整体保存配置 → 写 config.json → 采集器热同步 |
| `DELETE /api/config/instance/{name}?purge=` | 删除实例（purge=true 清除其数据） |
| `POST /api/collect?instance=` | 立即采集指定实例（异步，防重入） |
| `POST /api/collect/all` | 立即采集全部启用实例 |
| `GET /api/storage` | 本地存储占用（DB 文件大小、各表行数/字节估算、每实例数据量） |

### 设置视图（Settings，`/settings`）

- 全局：`collect_interval`、`cleanup`（自动清理）；`web.host/port` 只读（改监听端口需重启后端）。
- 实例列表：名称/地址/协议/启用/模块数/采集状态（**采集中·当前源·页进度·已采条数** / 最近采集 / 错误）+ 「立即采集」「编辑」「删除」；顶部「采集全部」。
- 编辑/新增表单：name/host/port/base/https/enabled/token（可见可编辑）+ 采集模块复选框 + **测试连接**（即时返回结果）。
- **状态自动轮询**：进入设置页后每 5s 刷新实例采集状态、每 15s 刷新本地数据。
- **本地数据卡片**：DB 文件实际大小 + logs/access_logs/ip_traffic/cursors 各表行数与估算字节 + 每实例数据量（日志/访问/流量 IP/字节）。
- 保存后采集器**热生效**（无需重启）：新增实例下一轮采集，参数变化/删除的实例关闭并移除缓存客户端。
- 删除实例默认保留其已采集数据（可勾选同时清除）；数据按实例名隔离。

### 采集并发与进度

- 多实例**并发采集（全局 HTTP 并发 ≤2，符合目标限制）**，新增实例无需等前面的实例采完。
- 采集状态字段：`collecting / current(当前源) / page / source_total / collected_rows / started_at`，随源实时更新（`system`、`docker`、`webservice/443`、`webservice/80/note`、`accessdetail:...`）。
- 首次全量为历史回填（游标=0），进度条显示「页 n/m · 已采 N 条」；`last_collect` 每次完成一轮即更新。

## 去重逻辑

- 入库：`logs` 唯一索引 `(instance, module, rule_key, sub_key, ts_text, content)`；`access_logs` 唯一索引 `(instance, sub_key, ts_text, client_ip, method, path)`。
- 查询：`dedup` 参数按 时间+内容 / 内容 / 关闭 切换（通用日志）。

## 技术要点

- 前端 Vue 3 + Vite，`frontend/src` 组件化；`npm run build` 产物到 `static/dist`，由后端托管。
- 开发期 Vite dev server（5173）代理 `/api` `/ws` 到后端（8666）。
- IP 归属地由后端 `geoip.py`（ip2region）在查询时标注，缺库/失败降级为"未知"。
