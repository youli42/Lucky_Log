# 06 - 可视化面板功能

## 页面布局

```
┌──────────────────────────────────────────────────────────┐
│ 顶部工具栏                                                     │
│  [实例切换▾] [模块▾] [服务▾] [实时/手动] [手动刷新] [导出▾]   │
│  时间: [近1h][6h][24h][自定义: from ~ to]  [搜索框] [去重▾]  │
├───────────────────────────────┬──────────────────────────────┤
│ 图表区                         │ 日志表格                       │
│  ├─ 模块分布（饼图）           │ 时间 | 模块 | 服务 | 内容      │
│  ├─ 时间趋势（折线）           │ (点击展开原始 JSON)            │
│  └─ 服务分布（柱状图）         │ (分页 / 滚动加载)              │
└───────────────────────────────┴──────────────────────────────┘
```

## 筛选器

| 控件 | 行为 |
|---|---|
| 实例切换 | 切换数据源（多实例），重新加载服务树与日志 |
| 模块 | 下拉：全部 / system / webservice / docker / cron / ddns / ssl / ... |
| 服务 | 联动下拉（模块=webservice 时）：规则名 + 子代理；选服务则查询 by_rule 数据 |
| 时间 | 快捷（近1h/6h/24h/7d）+ 自定义起止（`YYYY-MM-DD HH:mm:ss`） |
| 搜索 | 关键词，对 content LIKE 匹配 |
| 去重 | 键：时间+内容 / 内容 / 关闭 |

## 模式

### 实时模式
- 前端订阅 `WS /ws/stream`（带实例/模块过滤）
- 新日志实时插入表格顶部 + 图表增量更新
- 开启后自动建立 WS；断线自动重连
- 仍保留「手动刷新」按钮（立即拉一次最新）

### 手动模式
- 不订阅 WS；点击「手动刷新」才请求 `GET /api/logs` 最新数据
- 后端仍持续采集入库，手动刷新即查询最新

## 后端 API

| 接口 | 说明 |
|---|---|
| `GET /api/instances` | 实例列表 + 状态 |
| `GET /api/services?instance=` | 服务树 |
| `GET /api/modules?instance=` | 模块列表 + 条数 |
| `GET /api/logs?instance=&module=&service=&from=&to=&search=&dedup=&page=&pageSize=` | 日志分页查询 |
| `GET /api/stats?instance=&module=&from=&to=&granularity=` | 图表统计（按小时/模块/服务聚合） |
| `GET /api/export?instance=&module=&from=&to=&search=` | 导出 CSV / JSON |
| `WS /ws/stream` | 实时增量推送 |

## 去重逻辑

- 后端：查询时按所选去重键对结果集去重（SQL 分组或内存 Set）
- 默认「时间+内容」：`GROUP BY ts_text, content`
- 前端展示 `去重前 N 条 → 去重后 M 条`

## 导出

- CSV：`time,module,rule_name,sub_name,content`（UTF-8 BOM，Excel 兼容）
- JSON：完整字段数组

## 状态展示

- 每实例：最近采集时间 / 最近错误 / 各模块日志条数
- 顶部徽标：采集器运行中 / 连接失败

## 技术要点

- 前端单文件 `static/index.html`，无构建
- Chart.js 本地 vendor（可复用现有 vendor_chart.js 或 CDN 兜底）
- 时间区间较大时 stats 用 SQL 聚合，避免全量传输
- 表格用虚拟滚动/分页防卡顿（默认 200 条/页）
