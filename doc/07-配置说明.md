# 07 - 配置说明

> `config.json` 位于项目根目录。首次启动时若不存在会生成默认模板。

## 结构

```json
{
  "web": {
    "host": "0.0.0.0",
    "port": 8666
  },
  "collect_interval": 10,
  "cleanup": {
    "enabled": false,
    "days": 7
  },
  "instances": [
    {
      "name": "lucky-main",
      "host": "10.10.10.11",
      "port": "16601",
      "base": "/youlilucky",
      "token": "iNRzDVrcT8xCDk01NTp21iljPtb6qGdq",
      "https": true,
      "enabled": true,
      "modules": ["system", "webservice", "docker", "cron", "ddns", "ssl",
                  "webterminal", "rclone", "filebrowser", "wol"]
    }
  ]
}
```

## 字段说明

| 字段 | 默认 | 说明 |
|---|---|---|
| web.host | 0.0.0.0 | 后端监听地址 |
| web.port | 8666 | 后端端口 |
| collect_interval | 10 | 每实例采集间隔（秒） |
| cleanup.enabled | false | 是否自动清理旧日志（默认不清理） |
| cleanup.days | 7 | 清理保留天数（enabled=true 时生效） |
| instances[].name | — | 实例标识，必填唯一 |
| instances[].host | — | Lucky 主机 |
| instances[].port | — | 端口（字符串） |
| instances[].base | /youlilucky | SafeURL 前缀 |
| instances[].token | — | OpenToken，必填 |
| instances[].https | true | 是否 HTTPS（自签名证书自动忽略校验） |
| instances[].enabled | true | 是否参与采集 |
| instances[].modules | 全部 | 采集的模块白名单 |

## 多实例

- 列表可含多个实例，后端并行采集
- 前端顶部「实例切换」下拉切换查看
- 每实例独立游标与日志（`logs.instance` 字段区分）

## 模块白名单可选值

`system` `webservice` `docker` `cron` `ddns` `ssl` `webterminal` `rclone` `filebrowser` `wol` `ftpserver` `webdav` `dlnaservice` `frp` `cloudflared` `ipdb` `storagemanagement` `thirdPartyAuthManager`

> 后几项多为空日志，默认可不开启。

## 数据库与数据目录

- SQLite 文件：`data/logs.db`（运行时自动创建）
- 日志表：`logs`（见 doc/05）
- 清理策略对同一 DB 内所有实例生效
