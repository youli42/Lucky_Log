## 1. 项目内容概览

- **定位**：Lucky-Admin 的浏览器端日志可视化面板。拉取多 Lucky 实例各模块日志 → SQLite → Vue3 面板展示/筛选/图表/导出；额外提供 Web 访问日志结构化分析（IP/UA/归属地）与 Docker/SMB 面板。
- **规模**：24 个提交；后端 11 个 py 模块 + 8 个路由 + 10 个测试文件；前端 6 个视图 + 8 个组件 + store/composable；文档 9 篇 + 本评审。
- **数据现状**（data/logs.db，44.5MB）：logs 22,159 行（webservice 占 80%），access_logs 2,770，ip_traffic 563，cursors 106（2 实例 × ~53 源），docker_cache 2。
- **技术栈**：FastAPI + aiosqlite + httpx（verify=False 自签）+ ip2region + user-agents；Vue3 + Vite + Chart.js（hash 路由，构建产物入库 static/dist）。
- **架构亮点**：采集器（实例×源游标增量、全局并发≤2、指数退避+暂停防风控、404 跳过）；查询期富化（geoip/UA 不改表结构）；WebSocket 增量广播；Docker 快照本地缓存秒显。

## 2. 问题清单（按严重度）

### P0 — 已确认的功能缺陷（实测复现）

1. **`/api/export` 导出接口 100% 崩溃（NameError）**
   - 位置：`app/routes/logs.py` `export_logs`（JSON 分支 75 行、CSV 分支 84 行）。
   - 原因：函数签名无 `service` 参数，却以 `service=service` 传入 `db.export_rows` → `NameError: name 'service' is not defined`。
   - 影响：README、前端「CSV / JSON 导出」按钮全部失效；接口 500。
   - 修复：签名补 `service: Optional[str] = None` 并透传（与 `query_logs` 对齐），补一个路由级测试。

2. **总览页分页页数计算错误**
   - 位置：`frontend/src/views/Overview.vue` 模板 `:pager` 中 `Number(logPageSize.value)`。
   - 原因：模板里 ref 已自动解包，`logPageSize.value` 实为 `32.value` → undefined → `pageCount = logTotal`。
   - 影响：翻页器显示 `1 / 22159` 而非 `1 / 693`；翻页按钮行为仍可用但展示全错。
   - 修复：改为 `Number(logPageSize) || 1`（与 ModuleLogs/Access 的 computed 写法一致）。

### P1 — 安全与数据风险

3. **API 完全无鉴权 + 默认监听 0.0.0.0**
   - `/api/config` 明文返回全部实例 **OpenToken**；未鉴权即可：启停/重启/暂停 Docker 容器、断开 SMB 连接、删除实例（含 purge 数据）、修改采集配置。
   - 建议：至少默认绑 `127.0.0.1`；或加简单口令认证（前端登录 + FastAPI 中间件/依赖校验，静态资源除外）。OpenToken 在设置页回显为明文，建议脱敏（只显示尾 4 位）。

4. **access_logs 无清理机制**
   - `db.cleanup_old` 只删 `logs`；`access_logs`（及 `ip_traffic`）永久增长。Web 访问日志是增长最快的表之一，长期运行库会膨胀。
   - 建议：清理逻辑覆盖 access_logs；或按时间归档/分表。

5. **时间解析依赖本机时区（无 TZ 配置）**
   - `collector.parse_ts_text` / `access_parser.parse_ts` 用 `datetime.strptime`（naive 本地时区）转 epoch。若 Lucky 服务端时区 ≠ 采集机时区，全部时间戳系统性偏移，时间筛选/趋势图错位。
   - 建议：配置项声明 Lucky 端时区（或统一按 UTC 解析 + 展示层转换），至少文档明确此假设。

### P2 — 设计 / 性能 / 健壮性

6. **UA 解析与 geoip 富化无缓存**
   - `access.py _enrich` 对每行执行 `user_agents.parse`（同步 CPU 较重）+ 逐 IP geoip；导出 10 万行时开销显著；`/access/stats` 对 Top300 IP 富化后只取 15，浪费 95% 计算。
   - 建议：按 UA 字符串做 LRU 缓存 UA 解析结果；stats 只对最终展示的 15 个 IP 做 geo 富化。

7. **「全部历史 IP」全量内存处理**
   - `db.access_ips` 全表 GROUP BY，路由层对每个唯一 IP 逐次 geoip 查询 + Python 内存排序/分页。唯一 IP 上万后每页请求 O(n)。
   - 建议：排序下推到 SQL（可排序列已在白名单内），geo 富化按页（≤500）进行。

8. **SQLite 未开启 WAL / busy_timeout**
   - 全库单 aiosqlite 连接，无任何 PRAGMA。采集写入与查询并发时可能互相阻塞；`cleanup_old` 里 `VACUUM` 会长时间锁库（UI 卡顿）。
   - 建议：`PRAGMA journal_mode=WAL; PRAGMA busy_timeout=5000;`；VACUUM 改为后台任务或低频执行。

9. **raw_json 使库体积翻倍**
   - 每行存储完整原始 JSON（22k 行 → 44.5MB，行均 ~2KB），且与 content 字段重复。增长需规划。
   - 建议：raw_json 改存 gzip/裁剪字段（详情抽屉只用到 raw 展开），或加最大保留行数。

10. **空模块配置回退为「采集全部」**
    - `collector._collect_instance`：`set(inst.modules or SINGLE_SOURCES.keys())` — 用户清空模块列表（`[]`）会触发采集所有模块，与「清空=不采集」直觉相反。pydantic 默认值使该分支几乎不会被触发，但配置 `"modules": []` 时行为意外。

11. **采集周期语义与 UI 表述不符**
    - `_run_loop` 是「采集耗时 + collect_interval 固定 sleep」，非真正周期。实测单实例一轮 ~16s，配置 10s 实际 ~26s/轮。设置页/文档说「每轮采集间隔」易误导。

12. **WebSocket 推送健壮性**
    - `stream.py` 无心跳/ping，长空闲连接可能被中间代理静默断开（前端 2s 重连兜底，尚可）；广播发送完整行（含 raw_json），单批最多 2000 行时 payload 大；队列满直接丢（可接受但无提示）。

13. **Docker/SMB 路由每次请求新建 httpx client**
    - `routes/docker.py _client`、`routes/smb.py` 每个请求 new 一个 AsyncClient（TLS 握手开销）；面板每 10s 轮询多端点时浪费。建议复用 collector 的客户端池或按实例缓存。

14. **stats / overview 重复聚合无缓存**
    - `access_stats` 单次调用 ≈ 12 条聚合 SQL + traffic_map；总览/访问页多视图各自重复调用。数据只增不改，可加短 TTL 结果缓存。

15. **Access 页筛选输入无防抖**
    - `watch([rule, sub, host, search], …)` 每个搜索字符触发 3 个接口（stats/detail/ipList）重载。建议输入防抖（如 300ms）。

16. **geoip 加载失败无负缓存**
    - `geoip._load` 失败后置 None，每次查询重试加载 11MB xdb（含 import）。建议失败后冷却一段时间。

17. **测试缺口直接导致 P0 漏网**
    - 后端 65 个测试覆盖了解析/退避/DB/配置/路由，但**没有任何路由级导出测试**（/api/export 崩溃未被发现）；**前端零测试**（无 vitest、无组件/E2E）。README 宣称的功能与测试覆盖不匹配。

18. **代码卫生小项**
    - `__import__("json")`、`__import__("time")` 内联动态导入（collector.py:89/114、routes/logs.py:92、docker.py:53）；`normalize_record`/`normalize_system_record` 重复；`routes/access.py _enrich` 与 `/stats` 内联富化逻辑重复；`Sidebar.vue` `m.to` 永不定义（死代码）；`TopBar.vue` `emit('range-change')` 无监听方（死代码）、`getElementById('fromInput')` 硬编码。
